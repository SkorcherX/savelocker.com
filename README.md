# savelocker.com

The marketing site for [SaveLocker](https://github.com/SkorcherX/SaveLocker). Astro + Tailwind v4,
static output, deployed on Cloudflare Pages.

## Run it

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # -> dist/
npm run preview
```

**Node 22.12+ is required** (Astro 7). `.node-version` pins the version Cloudflare Pages builds
with — keep it in step with whatever you run locally.

## Layout

```
src/
├── layouts/Base.astro        # <head>, meta + OG tags, nav, footer
├── components/
│   ├── Nav.astro             # Sticky header
│   ├── Footer.astro          # Licence, trademark and attribution notices live here
│   ├── BrowserFrame.astro    # CSS browser chrome around a screenshot
│   ├── FeatureRow.astro      # Alternating screenshot/claim row
│   ├── SyncDiagram.astro     # Hand-built SVG: pull before launch, push after exit
│   ├── CodeBlock.astro       # Code + copy-to-clipboard button
│   ├── Callout.astro         # note / warn box
│   └── Tabs.astro            # Windows / Steam Deck switcher (max 3 panels)
├── pages/                    # index, start, faq
└── styles/global.css         # Palette + base + component layers
public/
├── screenshots/              # See ASSETS.md — several still need re-capturing
├── img/logo.png
└── og.png                    # Generated by scripts/make-og.mjs
```

## The two traps in this repo

**1. Never write an unlayered rule in `global.css`.** Tailwind v4 emits utilities into the
`utilities` cascade layer, and unlayered CSS beats layered CSS regardless of selector strength. A
bare `* { margin: 0; padding: 0 }` — which Preflight already does — silently defeated every `m-*`
and `p-*` utility on the site and un-centred every container. Everything goes in `@layer base` or
`@layer components`.

**2. Astro drops the whitespace when a tag starts a new line mid-sentence.** This renders as
`ClickMore info`, not `Click More info`. Write `{' '}` at the end of the preceding line. Catch
regressions by scanning rendered text for a lowercase letter followed directly by a capital.

## Copy

[`COPY.md`](COPY.md) is the source of record for the wording, including the voice rules and the
positioning note on OpenSave. Change the copy there and in the components together.

Three rules that matter more than the rest:

- **Never say "open source."** SaveLocker is PolyForm Noncommercial — source-available, not OSI.
- **No numbers we haven't counted.** No game counts, no percentages, no user counts.
- **No implied Valve endorsement.**

## Colours

The palette in `src/styles/global.css` is lifted verbatim from `web/src/index.css` in the main
SaveLocker repo so the site and the product can't drift. If a colour changes there, change it here —
don't eyeball it.

## Social card

`node scripts/make-og.mjs` regenerates `public/og.png` (1200×630). The PNG is committed, so the
build never depends on the script. Re-run it if the wordmark or tagline changes.
